# 仲裁包（第三人裁决，先盲后明）

范围：两列不一致的 8 条——RQ2 五条（rq2_007、019、023、025、029），RQ3 三条（rb021、rb024、rb033）。

仲裁人资格：独立第三人——不是第二标注者，也未参与第一列（作者 LLM 辅助）标注；按包内判据独立判断。

流程：

1. 先填 `01_ARBITRATION_BLIND.md`（只有原始盲评材料，与第二标注者所见一致；不含任何一列标签）。
2. 填完记录其 SHA-256（`shasum -a 256 01_ARBITRATION_BLIND.md`），此后不再回改。
3. 再打开 `02_ARBITRATION_INFORMED.md`，对照两列后填 `final` 与理由；若 `final` 与盲判不同，理由须说明为何改判。
4. `final` 只能取本 RQ 合法标签（RQ2 的 `y`/`n`；RQ3 三选一），不得留白、不得造新标签；每条配一句理由。
5. 两可时按保守规则：RQ2 倾向 `n`；RQ3 倾向 `SUSPECTED_REGRESSION`。
6. `final` 为最终口径：RQ2 语义有效率、RQ3 三类分布以它为准；两列各自对 `final` 的一致率照常报告。

正文披露：仲裁人为独立第三人，采用先盲后明程序；RQ2 与 RQ3 的 Cohen's κ 按原两列计算（κ=0 系第二列为常量所致，患病率悖论），裁决不改变该事实。

注意：`rb033` 即正文 §5.3 协议 B 单列条目；若其 `final` 裁为 STRUCTURAL_ONLY，§5.3 对应表述需调整（属结论改动，单独记录）。
